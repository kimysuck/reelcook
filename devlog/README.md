# 개발 일지 카드 (인스타그램용)

영석님의 비공개 인스타 계정에 올리는 **날짜별 개발 일지 카드**를 만드는 도구입니다.
카드: 1080×1350(4:5) JPG · 앱 색(고추장 빨강 #D23B1F · 노른자 #FFB81C · 애호박 #3E8B3A) · Noto Sans CJK KR.

## 만드는 법
```bash
python3 devlog/build.py            # devlog/out/cards.html 생성
python3 devlog/shot.py             # 전체 카드를 devlog/out/*.jpg 로 저장
python3 devlog/shot.py d6          # Day 6 카드만
```
- 크롬은 `CHROME_PATH`가 있으면 그것을 쓴다(Claude Code 클라우드). 없으면 Playwright 기본 크롬.
- 결과물(`out/`)과 개인 자료(`private/`)는 git에 올리지 않는다(.gitignore). 저장소는 **공개**다.

## 구성
| 파일 | 역할 |
|---|---|
| `build.py` | 카드 내용 + 틀. 위쪽에 도우미 함수(`rows`, `bullets`, `phones`, `code`), 아래에 `DAYS`(고정 게시물 `pin`, Day 1~5) |
| `style.css` | 카드 디자인 |
| `shot.py` | 카드 → JPG |
| `img/` | 앱 화면(테스트 영상으로 찍은 것, 남의 릴스 없음) |
| `private/` | 공개하면 안 되는 내용(개발 동기 본문, 광고 영상 장면). 없으면 자리 표시만 나온다 |

## 새 날짜(Day N) 추가 규칙
1. `git log --since` 로 마지막 일지 이후 커밋을 모은다(한국 시간 기준 날짜로 묶는다).
2. `build.py`의 Day 5 블록을 본떠 `dN = []` … `DAYS.append((N, dN))` 를 추가한다.
   - 첫 장: `'cover'` (날짜·요일, 제목, 요약, 커밋 수·버전·핵심 숫자, 칩)
   - 문제 해결 카드: `rows([('현상','bad'),…('원인','why'),('해결','good'),('결과','res')])` + 필요하면 `code()`
   - 기능 카드: `bullets([...])` + `phones([...])` (화면은 `img/`에 jpg로 추가)
   - 마지막 장: "DAY N 정리" 표(시간·버전·내용) + 다음 과제
3. 문장은 전문적으로: 구어("왔다 갔다", "꺼짐") 대신 현상·원인·조치를 명확히. 과장·추측 금지, 커밋에 있는 사실만.
4. 비밀 키·이메일·실명·가족 이야기·남의 릴스 장면은 카드와 저장소에 넣지 않는다.
5. 캡션 초안도 함께 만든다: `[릴쿡 개발 일지 Day N] 제목` → 2~4문장 요약 → `· 커밋 n건 · vX → vY` → 해시태그(#릴쿡 #개발일지 …).
6. 만든 JPG는 영석님께 전달하고, 개발 일지 문서(claude.ai Docs "릴쿡 개발 일지 (2026.11)")에 표·캡션을 붙여 넣도록 안내한다.
